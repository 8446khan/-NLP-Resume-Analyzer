# 📄 NLP Resume Analyzer

An NLP-based Resume Analyzer built using Python and Flask that provides text analysis capabilities through Sentiment Analysis, Word Analysis, Syntax Analysis, and Matching. The project leverages Natural Language Processing and Machine Learning libraries to analyze textual content.

## 🚀 Project Overview

The NLP Resume Analyzer is a Python-based web application designed to process and analyze text using various NLP techniques. It includes multiple analysis modules to explore text sentiment, word patterns, syntactic structure, and text matching.

## ✨ Features

- 😊 **Sentiment Analysis** – Analyze the sentiment and polarity of text using TextBlob.
- 🔤 **Word Analysis** – Perform word-level analysis and explore textual patterns.
- 🧩 **Syntax Analysis** – Analyze sentence structure and linguistic patterns.
- 🎯 **Matching Analysis** – Perform text matching and similarity analysis.
- 📄 **Resume Analysis** – Process resume-related textual content.
- 🌐 **Flask Web Application** – Access analysis functionalities through a web interface.
- 🐍 **Modular Python Implementation** – Organized using Python files and `app.py`.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/NLP-Resume-Analyzer.git
```

### 2. Navigate to the Project Directory

```bash
cd NLP-Resume-Analyzer
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

```text
http://127.0.0.1:5000
```
